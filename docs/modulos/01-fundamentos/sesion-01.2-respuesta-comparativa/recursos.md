# Sesión 01.2 — Recursos complementarios

Material para mantener la comparativa actualizada y profundizar en evaluación rigurosa de LLMs.

---

## Datos vivos para mantener tu comparativa actualizada

- **Artificial Analysis** — el agregador más actualizado de precios, latencia, calidad, contextos. Recurso fundamental.
  - https://artificialanalysis.ai
- **Hugging Face — Open LLM Leaderboard** — ranking de modelos open-source en benchmarks estándar.
  - https://huggingface.co/spaces/open-llm-leaderboard/open_llm_leaderboard
- **LMSys Chatbot Arena** — ranking por preferencia humana en comparaciones ciegas. El benchmark "humano" más confiable.
  - https://lmarena.ai
- **AIDER LLM Leaderboard** — ranking específico para tareas de programación. Útil cuando elegís modelo para casos de código.
  - https://aider.chat/docs/leaderboards/

## Vercel AI SDK — temas relacionados

  - https://ai-sdk.dev/docs/ai-sdk-core/prompt-caching

## Sobre evaluación de LLMs (preview profundo de M4)

- **Hamel Husain — _Your AI Product Needs Evals_** — el post fundacional sobre por qué evaluar es crítico y cómo arrancar.
  - https://hamel.dev/blog/posts/evals/
- **Jason Liu — _Beyond Benchmarks_** — cómo construir eval sets propios de tu producto.
  - https://jxnl.co/writing/2024/05/12/beyond-benchmarks/
- **RAGAS docs** — framework de evaluación específico para sistemas RAG. Lo vas a usar en M4.
  - https://docs.ragas.io/
- **Promptfoo** — framework de testing de prompts y comparativas. Lo vas a usar en M4 también.
  - https://www.promptfoo.dev/
